AI & Deep Learning Dictionary

Over 40+ rigorous mathematical and architectural definitions covering Neural Networks, Transformers, LLMs, and Multi-Agent Swarms.

Self-Attention (Scaled Dot-Product)

An attention mechanism relating different positions of a single sequence to compute a representation of the sequence via Softmax((QK^T)/sqrt(d_k))V.

LoRA (Low-Rank Adaptation)

A PEFT technique that freezes base LLM weights and injects trainable rank decomposition matrices into transformer layers.

Backpropagation

An algorithm for computing the gradient of the loss function with respect to all neural network weights via the multivariate chain rule.

ReAct (Reason + Act)

An agentic framework interleaving step-by-step verbal reasoning traces with environment tool invocations.
